# KDE Plasma Dotfiles

Репозиторий для версионирования, резервного копирования и синхронизации ключевых конфигурационных файлов рабочего окружения **KDE Plasma** (поддерживаются Plasma 6 и Plasma 5).

---

## 📁 Структура каталогов

```text
~/dotfiles/kde/
├── .git/                     # Локальный git-репозиторий
├── .githooks/                # Git-хуки для безопасности
│   └── pre-commit            # Хук, блокирующий коммит приватных ключей, токенов и паролей
├── .gitignore                # Строгий список исключений чувствительных файлов и кэша
├── README.md                 # Документация по установке и использованию
├── install.sh                # Bootstrap-скрипт полного развертывания на чистой системе
├── packages.txt              # Список пакетов оформления, шрифтов и виджетов (pacman/paru)
├── backup.sh                 # Скрипт синхронизации из ~/.config в репозиторий
├── restore.sh                # Скрипт развертывания настроек из репозитория в ~/.config
├── scripts/
│   └── verify-security.sh    # Скрипт верификации файлов на отсутствие секретов
└── config/                   # Конфигурационные файлы KDE Plasma
    ├── dolphinrc             # Настройки файлового менеджера Dolphin
    ├── kdeglobals            # Цвета, шрифты, стили виджетов, глобальное оформление
    ├── kglobalshortcutsrc    # Глобальные горячие клавиши
    ├── konsolerc             # Конфигурация эмулятора терминала Konsole
    ├── kwinrc                # Настройки оконного менеджера KWin (эффекты, фокус, поведение)
    ├── kwinrulesrc           # Правила окон KWin (поведение окон конкретных приложений)
    ├── plasma-org.kde.plasma.desktop-appletsrc # Панели, системный трей и апплеты рабочего стола
    └── plasmarc              # Общие параметры оболочки Plasma
```

---

## 📄 Назначение ключевых конфигурационных файлов

| Файл | Описание |
| :--- | :--- |
| `config/kdeglobals` | Системная цветовая палитра, системные шрифты, стиль значков и базовые параметры тем оформления Qt/KDE. |
| `config/plasmarc` | Глобальные настройки рабочей среды Plasma, поведение переключателей виртуальных рабочих столов и тем рабочего стола. |
| `config/kwinrc` | Параметры оконного менеджера KWin: настройки анимаций, эффектов рабочего стола, тайлинга, переключения окон и отклика мыши. |
| `config/breezerc` | Детальные настройки стилей темы оформления Breeze (тени окон, анимации кнопок, отрисовка рамок окон). |
| `config/kglobalshortcutsrc` | Глобальные сочетания клавиш KDE (управление окнами, громкостью, яркостью, запуск приложений и шорткаты виджетов). |
| `config/plasma-org.kde.plasma.desktop-appletsrc` | Структура и состав панелей Plasma: виджеты, системный трей, меню запуска приложений, цифровые часы и параметры рабочих столов. |
| `config/kwinrulesrc` | Специальные правила KWin для управления окнами конкретных программ (фиксация геометрии, пропуск таскбара, полноэкранный режим, прозрачность). |
| `config/dolphinrc` | Параметры файлового менеджера Dolphin (режим отображения файлов, панель предпросмотра, фильтры и сортировка). |
| `config/konsolerc` | Профили и глобальные настройки эмулятора терминала Konsole. |

## 🛡️ Безопасность и фильтрация

Репозиторий настроен на предотвращение утечек приватных данных:
1. **`.gitignore`** исключает:
   - Кэш активностей и историю: `kactivitymanagerd*`, `*recentdocuments*`, `*history*`, `*state*`
   - Кошельки, пароли, ключи и токены: `kwallet*`, `*token*`, `*secret*`, `*auth*`, `*.key`, `*.pem`
   - Сессионные файлы: `ksmserverrc`, `session/`
   - Временные файлы, логи, сокеты, дампы: `*.log`, `*.tmp`, `*.bak`, `*.lock`, `kde_backup_*`
2. **Pre-commit хук** (`.githooks/pre-commit`):
   - Автоматически проверяет индексируемые файлы через `grep -Ei` на наличие персональных токенов, приватных ключей, паролей и названий защищенных файлов перед каждым коммитом.
   - Блокирует создание коммита, если обнаружены конфиденциальные строки.
3. **Скрипт верификации** (`scripts/verify-security.sh`):
   - Может быть запущен вручную в любой момент для аудита каталога `config/`.

## 🚀 Быстрое развертывание на чистой системе (`install.sh`)

Скрипт **`install.sh`** автоматизирует все шаги развертывания под ключ:
1. Проверяет наличие пакетного менеджера (`paru`, `yay` или `pacman`).
2. Сравнивает список из `packages.txt` с установленными в системе и предлагает доустановить недостающие пакеты оформления, шрифтов и виджетов.
3. Вызывает `restore.sh` для наката конфигураций (с созданием бэкапа в `~/.config/kde_backup_<timestamp>`).
4. Корректно перезапускает сессию через `qdbus6 org.kde.KWin /KWin reconfigure` и `systemctl --user restart plasma-plasmashell`.

### Запуск:

```bash
cd ~/dotfiles/kde
chmod +x install.sh restore.sh backup.sh .githooks/pre-commit scripts/verify-security.sh
git config core.hooksPath .githooks

# Тестовый прогон (симуляция):
./install.sh --dry-run

# Боевая установка:
./install.sh

# Автоматическая установка без интерактивных запросов:
./install.sh -y
```

## 🔧 Ручное развертывание (`restore.sh`)

Если требуется накатить только конфигурационные файлы без проверки системных пакетов:

```bash
# Режим симуляции
./restore.sh --dry-run

# Символические ссылки (рекомендуется)
./restore.sh

# Или копирование файлов
./restore.sh --copy
```

Для ручного перезапуска компонентов оболочки:
```bash
# Plasma 6
systemctl --user restart plasma-plasmashell
qdbus6 org.kde.KWin /KWin reconfigure

# Plasma 5
kquitapp5 plasmashell && kstart plasmashell
qdbus org.kde.KWin /KWin reconfigure
```

## 🔄 Синхронизация изменений (Backup)

После изменения настроек через графический интерфейс KDE (Системные настройки, виджеты, панели):

1. **Запуск бэкапа**:
   ```bash
   cd ~/dotfiles/kde
   ./backup.sh
   ```
   Скрипт покажет `diff` каждого измененного файла и скопирует обновленные версии в `config/`.

2. **Обновление списка пакетов (при необходимости)**:
   ```bash
   pacman -Qqe | grep -Ei "plasma|breeze|kvantum|font" | sort -u > packages.txt
   ```

3. **Просмотр изменений и фиксация в git**:
   ```bash
   git status
   git diff
   git add config/ packages.txt
   git commit -m "style(kde): update panel widgets and shortcuts"
   ```
